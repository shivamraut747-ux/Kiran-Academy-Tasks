Recruitment & Placement Management System - UI Prototype (12 pages)

HOW TO OPEN
1. Open login.html in any web browser (double-click the file).
2. Click "Login" to reach the dashboard. Use the left menu to move between pages.
3. No internet, server or installation is needed. Forms do not save data; all records are sample data.

PAGES
login, dashboard, candidates, candidate-form, candidate-details, companies, jobs, job-form,
applications, interviews, placement-process (3 tabs), reports.
Shared style: css/style.css. Logo: images/logo.png. Screenshots of every page: screenshots/.

NAVIGATION FLOWS
Candidate: Login > Dashboard > Candidates > Add Candidate > Candidate Details > Applications
Job: Dashboard > Jobs > Create Job > Jobs list > View Applications
Application: Applications > Schedule Interview > Interviews > Add Feedback > Placement Process > Reports
